# Unlocked

A mobile-first PWA city guide for real local intelligence. The first edition is Nairobi: hidden gems, food, slang, movement tips, cultural etiquette, guides, and saved places.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

```bash
npm run lint
npm run build
npm run start
```

## Data model

Mock data lives in `data/` and is keyed by `cityId` so future editions can be added without changing the UI architecture.
